# PAIGE Desktop

For software work, start with Flow by Flow. For UI/UX work, also apply Impeccable and follow the [PAIGE UI design standard](docs/UI-DESIGN.md). It defines how to choose the task-specific design skill and what to verify in the Windows app.

Use the existing PAIGE design tokens, components, workflows, Workbench, and native approval path. Keep work within the selected project outcome. Show exact changes and verification evidence, with independent non-author review where required.
